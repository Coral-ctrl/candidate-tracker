## What we're looking for

- TypeScript or JavaScript, with Node.js on the backend and React on the frontend
- Designing REST APIs and working with a database (MongoDB or PostgreSQL)
- Writing automated tests that catch real problems
- Comfortable using AI tools, and able to judge what they produce
